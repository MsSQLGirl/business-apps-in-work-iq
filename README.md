# Business Apps in Work IQ

Demo kits, projects, and tips for using Business Apps in Work IQ to help Copilots and agents understand enterprise business data and take governed action.

## Demo kits

### Zava Capital dispute demo

A fictional-bank scenario for investigating credit-card disputes with Copilot Chat, Cowork, GitHub Copilot CLI, and a custom Dispute Analyzer agent.

- [Scenario, demo prompts, and setup instructions](demo-kits/zava-dispute/README.md)
- [Download the demo kit](demo-kits/zava-dispute/Zava-Dispute-Demo-Kit-External.zip)

The kit includes a Power Platform solution and a package for loading demo data. Review the setup instructions before importing the solution or loading data into a dedicated non-production environment.
